## 🔄 Data Flow Examples

### Example 1: Mark Upload → PO Attainment

```
1. Lecturer uploads Excel file (marks.xlsx)
   ↓
2. ExcelImportService.parseExcel()
   ├── Extract marks by student, LO, assignment
   ├── Validate (0-100, within max)
   └── Create StudentMark rows
   ↓
3. POAttainmentService.calculateStudentPOCredits()
   ├── Sum marks per LO (across assignments)
   ├── Apply pass/fail threshold
   └── Award PO credits based on mappings
   ↓
4. Frontend displays credits in StudentPOSummaryPage
   └── ❌ Data NOT persisted, lost on refresh
```

### Example 2: CQI Cycle

```
1. Admin finalizes batch via CQI endpoint
   ├── Calculates batch LO attainment
   └── Calls CQIService.checkAndTriggerCQI()
   ↓
2. CQIService.checkAndTriggerCQI()
   ├── For each LO in module:
   │  ├── Get batch attainment %
   │  ├── Compare with threshold
   │  └── If < threshold & no open action:
   │     └── Create CqiAction (PLANNED)
   ↓
3. Lecturer views MyCqiPlansPage
   ├── See assigned CQI actions
   ├── Submit plan via CqiActionController
   └── CQIService.submitPlan() marks as submitted
   ↓
4. Admin reviews via CqiReviewPage
   ├── See pending plans
   ├── Approve via CqiActionController
   └── CQIService.approvePlan() → IN_PROGRESS
   ↓
5. Next semester, finalize new batch
   └── CQIService.linkNextSemesterResult()
      ├── Compare new attainment with target
      └── If target met: status → COMPLETED
```

### Example 3: Student Progress Report

```
1. Admin configures curriculum via ProgressConfigurationPanel
   ├── Select modules, LOs, POs
   ├── Set thresholds
   ├── POST /api/reports/progress/configuration/curricula
   └── ProgressService saves qa_curriculum row
   ↓
2. Admin records student attempts
   ├── Create qa_module_enrolment rows
   ├── Set status (PASS, FAIL, ABSENT, etc.)
   ├── Mark one as official (for OFFICIAL policy)
   ├── PUT /api/reports/progress/configuration/enrolments
   └── ProgressService validates & saves
   ↓
3. Lecturer generates report via StudentReportsPage
   ├── Search student
   ├── Click "Generate and preview"
   └── POST /api/reports/progress/students/snapshots
   ↓
4. ProgressService.generateProgressSnapshot()
   ├── Load curriculum config
   ├── Get student enrolments
   ├── AttainmentCalculator.select() applies retake policy
   ├── Calculate LO percentages
   ├── Calculate PO percentages
   ├── Check graduation requirements
   ├── Create immutable snapshot JSON
   └── Save to qa_report_snapshot
   ↓
5. User downloads PDF
   └── GET /api/reports/progress/snapshots/{ref}/pdf
      └── ProgressPdf generates PDF from snapshot
```
